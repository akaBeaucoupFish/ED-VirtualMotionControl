# ==============================================================================
# Axes Definitions
#     X  = Camera: Track 	Ship: Lateral Axis (Lt-0-Rt)
#     Y  = Camera: Boom 	Ship: Vertical Axis (Dn-0-Up)
#     Z  = Camera: Dolly 	Ship: Forward/Reverse Axis(Rv-0-Fw)
#     rX = Camera: Roll 	Ship: Roll (Lt-0-Rt)
#     rY = Camera: Tilt		Ship: Pitch (Dn-0-Up)
#     xZ = Camera: Pan 		Ship: Yaw (Lt-0-Rt)
# ==============================================================================

# ------------------------------------------------------------------------------

# KEYUP key
# KEYTAP key
